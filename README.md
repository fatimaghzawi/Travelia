# Travelia

**Travelia** is a full-stack travel guide and booking platform. Travelers discover destinations, verify their passport once, plan trips, and book activities. Administrators manage content, verify users, and monitor operations from a dedicated dashboard.

Built with **Next.js 16**, **TypeScript**, **MongoDB**, and **Mongoose**, using a **mobile-first** design system.

Overview

Travelia is a comprehensive travel platform designed to simplify the entire travel journey—from discovering destinations to managing bookings and itineraries.

The platform enables travelers to explore curated destinations, create personalized trips, verify their identity through a one-time passport verification process, book experiences securely, manage budgets, track travel history, and receive personalized recommendations.

Administrators have access to a powerful dashboard for managing destinations, bookings, users, activities, reviews, and platform content while monitoring overall system operations.

Travelia follows a modern mobile-first architecture with a strong focus on performance, scalability, accessibility, and user experience.
